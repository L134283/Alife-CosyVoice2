# CosyVoice2 语音合成

基于本地 **CosyVoice2（yinmei）** 的 Alife 语音合成插件。由插件自动拉起本地 Python 服务，对接 `ISpeechModel`，供语音输出链路使用。

> 依赖：`Alife.Function.Speech`  
> 本地服务：yinmei-cosyvoice（需自行安装模型与 Python 环境）

## 功能

| 功能 | 说明 |
|------|------|
| **本地 TTS** | 调用本机 CosyVoice2 API 合成 wav |
| **自动启动** | 可自动拉起 `start.py`，也可复用已在跑的服务 |
| **健康检查 / 守护** | 周期探测，连续失败后自动清理并重启 |
| **残留清理** | 按 PID 文件 + 端口查杀进程树；Windows Job 绑定，主进程异常退出时带走子进程 |
| **音色列表** | 从 `/get_spk` 拉取；UI 可刷新；无效音色自动回退 |
| **风格指令** | 可选 `instruct`；**留空则不传**，使用音色默认语气（不会按文案自动换情绪） |
| **语速** | `speed`，1.0 为正常 |
| **请求重试** | 服务未就绪 / 真忙时短退避重试；不可朗读文本不请求 |
| **同句缓存** | 相同文本+音色+语速+指令会复用已生成文件；并发同句去重 |
| **取消联动** | 调用方取消且无人等待时，停止后台 InFlight 重试 |
| **预热** | 就绪后合成一句「你好」，降低首句延迟 |
| **配置 UI** | 音色、语速、风格、路径、端口、模式等可视化配置 |
| **干净日志** | 控制台仅输出 `[Cosy语音] …`，无 `info: Namespace.Class[0]` 前缀 |

## 快速上手

1. 安装并准备好 **yinmei-cosyvoice**（Python、项目目录、CosyVoice2 模型）
2. 在角色配置中启用 **语音相关模块**，并启用本插件「Cosy语音合成」
3. 在插件 UI 中填写：
   - Python 路径
   - 项目目录（含 `start.py`）
   - 模型目录
   - API 端口（默认 `9981`）
4. 建议 **启动模式 = 1（仅 API）**，省资源
5. 保持 **自动启动** 开启（若你已手动起服务，可关掉）
6. 选择音色、语速；风格指令按需填写
7. 保存配置后重启/重载角色，看到日志就绪即可

### 就绪日志示例

```
[Cosy语音] 已启动（模式 1）
[Cosy语音] 服务启动中…
[Cosy语音] 等待模型加载…（1）
[Cosy语音] 预热完成
[Cosy语音] 服务就绪，音色 21 个
```

## 配置说明

| 配置 | 默认 | 说明 |
|------|------|------|
| API 地址 | `http://127.0.0.1:9981` | 与端口一致时会自动对齐 |
| 音色 | `女主持` | 对应 `/get_spk` 名称 |
| 语速 | `1.0` | 大于 0 |
| 风格指令 | 空 | 如「用开心的语气说」；**空 = 不传 instruct，默认语气** |
| Python 路径 | 本机路径 | yinmei 自带 `python.exe` |
| 项目目录 | 本机路径 | 含 `start.py` |
| 模型目录 | 本机路径 | 如 `pretrained_models/CosyVoice2-0.5B` |
| API 端口 | `9981` | TTS / 音色接口 |
| WebUI 端口 | `9980` | 仅 mode 2/3 |
| 流式切片 | `10` | `limit_count`，越小首包越快 |
| 启动模式 | `1` | `1` 仅 API（推荐）/ `2` 仅 WebUI / `3` 都开 |
| 自动启动 | 开 | 关则只连接已有服务 |
| 请求超时 | `120` 秒 | 单次合成 HTTP 超时 |
| 就绪超时 | `180` 秒 | 等待模型加载上限 |
| 失败重启阈值 | `6` | 健康检查连续失败次数后重启 |

### 风格指令说明

| 填写情况 | 行为 |
|----------|------|
| **留空** | 请求不带 `instruct`，音色默认语气，相对稳定 |
| **填写** | 按指令控风格，如「用温柔的语气」「用开心的语气说」 |

插件**不会**根据文案内容自动选择情绪。

### 不可朗读文本

Cosy 服务对纯标点 / 空白（如 `...`、`！！！`、`——`）会稳定返回 500。  
插件在合成前会过滤此类文本，日志示例：

```
[Cosy语音][警告] 跳过不可朗读文本：「...」
```

## 依赖与环境

- **Alife 依赖**：`Alife.Function.Speech`
- **本机环境**（不由插件 pip 安装）：
  - yinmei-cosyvoice 项目
  - 对应 Python 解释器
  - CosyVoice2 模型文件
- 默认路径示例（请按本机修改）：

```
Python：D:\1TTS\yinmei-cosyvoice\python311\python.exe
项目：  D:\1TTS\yinmei-cosyvoice
模型：  D:\1TTS\yinmei-cosyvoice\pretrained_models\CosyVoice2-0.5B
```
